---
name: Dashboard table layout
description: The user's preference for concise tab content, latest announcements at table center, and square badges without “YOU.”
---

In the player dashboard, do not repeat a tab name as a visible heading or add static helper instructions where the tab or interactive elements already provide the context. The player table should not show a generic ticker, condition tag, round counter, or branded “WORLD WAR TABLE” center box. Show the latest Round Announcement in the table center while keeping the full announcement history in Review. Keep player badges square and preserve their information and accessible names, but do not add a “YOU” label to the player's own badge. Place the Round Closure Consensus card directly below the live table in the Act tab, with host round controls next to the Ready button. The separate TV feed can retain its brand and live status display.

**Why:** the user requested a less cluttered player dashboard, latest announcements at table center without the brand box, square player badges without “YOU,” and round controls below the live table.

**How to apply:** Keep only the latest announcement in the player-table center and the full feed in Review. Preserve per-player details, keep consensus and host controls below the live table in Act, and leave the separate TV broadcast display intact.
